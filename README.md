# ระบบยืม-คืนหนังสือ ห้องสมุด — เวอร์ชัน 2.0 คู่มือติดตั้ง
ระบบแบ่งเป็น 2 ส่วน

| ส่วน | อยู่ที่ไหน | ไฟล์ (โฟลเดอร์ในชุดนี้) | ทำหน้าที่ |
|---|---|---|---|
| **หลังบ้าน** | Google Sheets + Apps Script (บัญชีหน่วยงาน) | `apps-script/` : Code.gs, Categories.gs, appsscript.json | เก็บข้อมูล ตรวจ PIN ออกเลขรับ ส่ง Telegram |
| **หน้าเว็บ** | GitHub Pages (ฟรี) | `github/` : index.html, search.html, receive.html, shelve.html, approve.html, links.html, style.css, common.js, config.js | หน้าที่ทุกคนเปิดใช้ |

**ทำไมแยก:** ถ้าเปิดหน้าเว็บจาก Apps Script ตรง ๆ เบราว์เซอร์ที่ล็อกอิน Google ไว้ (โดยเฉพาะหลายบัญชีหรือบัญชีองค์กร) จะขึ้น "ไม่สามารถเปิดไฟล์ได้" หน้าเว็บบน GitHub เรียกหลังบ้านแบบ **ไม่แนบบัญชี Google** จึงเปิดได้ทุกเครื่อง

---

## ส่วน A — หลังบ้าน (Apps Script)

### A1 สร้างชีตและวางโค้ด
1. ใช้บัญชี Google ของหน่วยงาน สร้าง Google Sheets ใหม่ แล้วตั้ง **ไฟล์ > การตั้งค่า** เป็น ภูมิภาค = ประเทศไทย, เขตเวลา = Bangkok
2. **ส่วนขยาย > Apps Script**
3. ไฟล์ `Code.gs` ที่มีอยู่: ลบของเดิมทิ้ง แล้ววางเนื้อหาจาก **Code.gs**
4. กด **+ > สคริปต์** ตั้งชื่อ `Categories` แล้ววางเนื้อหาจาก **Categories.gs**
5. รูปเฟือง > ติ๊ก **แสดงไฟล์ Manifest "appsscript.json"** > เปิด `appsscript.json` แล้ววางทับด้วยไฟล์ในชุดนี้
6. Ctrl+S

> โปรเจกต์ Apps Script **ไม่ต้องมีไฟล์ HTML แล้ว** ถ้ามี Style, Common, Receive, Shelve, Loan, Approve, Search, Links จากเวอร์ชัน 1 ให้ลบทิ้งได้ (จุด 3 จุดข้างชื่อไฟล์ > ลบ)

### A2 สร้างตาราง
เลือกฟังก์ชัน `setupSystem` > **เรียกใช้** > อนุญาตสิทธิ์ (ถ้าเจอ "Google hasn't verified this app" กด ขั้นสูง > ไปที่ … > อนุญาต — ขึ้นครั้งเดียวกับเจ้าของบัญชี)
ชีตจะมี 5 แท็บ: หนังสือ, ยืม-คืน, หมวดหมู่, ตั้งค่า, บันทึกการแก้ไข

### A3 ตั้ง PIN (เก็บที่นี่เท่านั้น ห้ามใส่ในโค้ด ชีต GitHub หรือแชท)
รูปเฟือง > **คุณสมบัติของสคริปต์** > เพิ่ม `PIN_RECEIVE` (ผู้ลงรับ), `PIN_SHELVE` (ผู้จัดหมวด), `PIN_APPROVE` (ผู้อนุมัติ)
ใช้ 6 หลักขึ้นไป ไม่ซ้ำกัน · ผิดเกิน 5 ครั้ง ล็อก 10 นาที · เปลี่ยนได้ทุกเมื่อโดยไม่ต้อง Deploy

### A4 Deploy เป็น Web app (ทำครั้งแรกครั้งเดียว)
**ทำให้ใช้งานได้ > การทำให้ใช้งานได้รายการใหม่ > เว็บแอป** · ดำเนินการในฐานะ: **ฉัน** · ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน** (ห้ามเลือก "ทุกคนที่มีบัญชี Google")
คัดลอก URL ที่ลงท้าย `/exec` — นี่คือ **ลิงก์ API** ใช้ในขั้น C1

## ส่วน B — หน้าเว็บ (GitHub Pages)

### B1 สร้างบัญชีและที่เก็บไฟล์
1. สมัคร https://github.com ด้วยอีเมลของหน่วยงาน ชื่อผู้ใช้จะเป็นส่วนหนึ่งของลิงก์ เช่น `cntc-library`
2. มุมขวาบน **+ > New repository** · ชื่อ `library` · เลือก **Public** · กด **Create repository**
   (GitHub Pages ฟรีต้องเป็น Public — ทุกคนเห็นโค้ดหน้าเว็บได้ แต่ไม่มีข้อมูลลับ เพราะ PIN และข้อมูลอยู่ฝั่ง Google)

### B2 อัปโหลดไฟล์
1. ในหน้า repository กด **uploading an existing file** (หรือ **Add file > Upload files**)
2. ลากไฟล์ **ทั้ง 9 ไฟล์ในโฟลเดอร์ `github/`** ใส่ (ลากไฟล์ ไม่ใช่ลากโฟลเดอร์)
3. กด **Commit changes**

### B3 เปิด GitHub Pages
1. **Settings > Pages**
2. Source: **Deploy from a branch** · Branch: **main** · โฟลเดอร์ **/ (root)** > **Save**
3. รอ 1–2 นาที แล้วรีเฟรช ด้านบนจะขึ้น **Your site is live at** `https://<ชื่อผู้ใช้>.github.io/library/` — นี่คือ **ลิงก์หน้าเว็บ**

## ส่วน C — เชื่อม 2 ส่วนเข้าด้วยกัน

### C1 บอกหน้าเว็บว่าหลังบ้านอยู่ไหน
ใน GitHub เปิดไฟล์ `config.js` > กดรูปดินสอ (Edit) > ตรวจว่า `apiUrl` เป็นลิงก์ API จากขั้น A4 > **Commit changes**
(ไฟล์ที่ส่งให้ใส่ลิงก์ API ปัจจุบันไว้แล้ว ถ้าลิงก์ไม่เปลี่ยนก็ไม่ต้องแก้)

### C2 บอกหลังบ้านว่าหน้าเว็บอยู่ไหน
ใน Apps Script แก้บรรทัดบน ๆ ของ Code.gs
```
const SITE_URL = 'https://<ชื่อผู้ใช้>.github.io/library/';
```
(ต้องลงท้ายด้วย `/`) > Ctrl+S > **ทำให้ใช้งานได้ > จัดการการทำให้ใช้งานได้ > ✏️ > เวอร์ชัน: เวอร์ชันใหม่ > ทำให้ใช้งานได้**
ใช้สำหรับลิงก์หน้าอนุมัติใน Telegram และหน้าแจ้งย้ายเมื่อมีคนเปิดลิงก์ Apps Script เก่า

### C3 ลิงก์ที่ใช้งาน

| ใคร | ลิงก์ |
|---|---|
| คนยืม-คืน (ทำ QR จากลิงก์นี้) | `https://<ชื่อผู้ใช้>.github.io/library/` |
| ค้นหาหนังสือ (ทุกคน) | `…/library/search.html` |
| ผู้ลงรับ | `…/library/receive.html` |
| ผู้จัดหมวด | `…/library/shelve.html` |
| ผู้อนุมัติ | `…/library/approve.html` |
| **รวมลิงก์ทุกหน้า** (บุ๊กมาร์กอันเดียวพอ) | `…/library/links.html` |

### C4 ทำ QR
เปิดลิงก์คนยืม-คืนใน Chrome > คลิกขวา > **สร้างคิวอาร์โค้ดสำหรับหน้านี้** > ดาวน์โหลด > พิมพ์ติดห้องสมุด (ทดสอบสแกน 1 ครั้งก่อนติด)

## Telegram (ทำทีหลังได้)
1. @BotFather > `/newbot` > ได้ token > ใส่ `TELEGRAM_TOKEN` ในคุณสมบัติของสคริปต์
2. สร้างกลุ่ม เพิ่มผู้อนุมัติและบอท > พิมพ์ `/start` ในกลุ่ม
3. รัน `getTelegramChatId` > คัดลอก chat id (มีเครื่องหมายลบ) > ใส่ `TELEGRAM_CHAT_ID`
4. รัน `testTelegram` > ข้อความควรเข้ากลุ่ม
5. รัน `setupDailyTrigger` ครั้งเดียว

ข้อความที่ส่ง: ทันทีที่มีคนยืม · ทุกวันตอนเที่ยง (ช่วง 12:00–13:00) แยก 2 ข้อความ คือ **งานค้าง** (รออนุมัติ / ใกล้ครบ / เกินกำหนด) และ **คืนหนังสือเมื่อวาน** (`ชื่อ 10 ตัวอักษร - เลขรับ - ผู้คืน`) — วันไหนไม่มีก็ไม่ส่ง

## การใช้งานประจำวัน

| ใคร | ทำอะไร |
|---|---|
| ผู้ลงรับ | กรอกชื่อหนังสือ + จำนวนเล่ม + เลขทะเบียน (กรอก / เว้นว่าง / ติ๊ก "ไม่มีเลขทะเบียน") > บันทึก > เขียนเลขรับลงตรายาง · ลงผิด กด "ยกเลิกเลขรับนี้" ได้ (เฉพาะเล่มที่ยังไม่จัดหมวด) |
| ผู้จัดหมวด | ติ๊กเลือกเล่มจาก "รอจัดหมวด" ได้หลายเล่ม (มีช่องกรอง + เลือกทั้งหมดที่แสดง) > "จัดหมวด N เล่มที่เลือก" > หมวดใหญ่ > หมวดย่อย (พิมพ์เลขเรียกให้ระบบแนะนำได้) > บันทึก · เลือกหลายเล่ม ช่องเลขเรียกใช้กับทุกเล่ม เว้นว่างถ้าเลขต่างกัน · แก้หมวดเล่มบนชั้นที่แท็บ "แก้หมวดเล่มบนชั้น" |
| คนยืม-คืน | สแกน QR > ยืม: ค้นเล่ม > ใส่ชื่อ > ตำแหน่ง > ยืนยัน (หยิบไปได้เลย) / คืน: เลือกเล่ม > ยืนยัน · เล่มที่ถูกยืมอยู่จะบอกว่าใครยืมและยืมซ้ำไม่ได้ |
| ทุกคน | **ค้นหาหนังสือ**: ไม่พิมพ์ = ทุกเล่มเรียงตามชื่อ หน้าละ 10 รายการ ชื่อซ้ำรวมเป็นรายการเดียว · กรองสถานะได้ · ค้นแบบคำใกล้เคียง (ไม่สนวรรณยุกต์/จุด/เว้นวรรค พิมพ์ผิดเล็กน้อยได้ รู้จักคำย่อ พ.ร.บ. ป.พ.พ. ฯลฯ) ตัวเลขต้องพิมพ์ตรง |
| ผู้อนุมัติ | เลือกรายการ > อนุมัติ หรือ ไม่อนุมัติพร้อมเหตุผล · ผู้ยืมคืนแล้วแต่ลืมสแกน ใช้ "ปิดรายการ" |

ระบบทำให้เอง: เลขรับ `L{ลำดับ}/{ปี พ.ศ.}` เริ่ม 1 ใหม่ทุก 1 ม.ค. แก้/ลบไม่ได้ · เลขที่ยกเลิกไม่นำกลับมาใช้ · กันเลขทะเบียนซ้ำ · ครบกำหนด = วันยืม + 15 วัน · ทุกการกระทำเก็บในแท็บ บันทึกการแก้ไข

## การแก้ไขภายหลัง

| อยากเปลี่ยน | ทำที่ | ต้องทำอะไรต่อ |
|---|---|---|
| หมวดหมู่ | แท็บ **หมวดหมู่** ในชีต | ไม่ต้อง |
| วันยืม วันเตือน คำนำหน้าเลขรับ ตำแหน่ง เหตุผลไม่อนุมัติ | แท็บ **ตั้งค่า** (หลายค่าคั่นด้วย `|`) | ไม่ต้อง |
| เวลาส่งสรุป Telegram | แท็บ **ตั้งค่า** | รัน `setupDailyTrigger` ใหม่ |
| PIN, Telegram | คุณสมบัติของสคริปต์ | ไม่ต้อง |
| **หน้าตาหน้าเว็บ** (ไฟล์ใน `github/`) | GitHub: เปิดไฟล์ > ✏️ แก้ หรือ Add file > Upload files ทับชื่อเดิม > Commit | รอ 1–2 นาที แล้วรีเฟรชแรง (Ctrl+Shift+R) |
| **ตรรกะหลังบ้าน** (Code.gs) | Apps Script | **จัดการการทำให้ใช้งานได้ > ✏️ > เวอร์ชันใหม่** |

> ห้ามกด "การทำให้ใช้งานได้รายการใหม่" ใน Apps Script เพราะจะได้ลิงก์ API ใหม่ ถ้าเผลอกด ให้แก้ `apiUrl` ใน `config.js` บน GitHub ให้ตรงลิงก์ใหม่
> ลิงก์หน้าเว็บ (GitHub) และ QR ไม่เปลี่ยน ตราบใดที่ไม่เปลี่ยนชื่อผู้ใช้หรือชื่อ repository

## ปัญหาที่อาจเจอ

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| หน้าเว็บขึ้น "เชื่อมต่อระบบไม่ได้" | ตรวจ `apiUrl` ใน config.js ให้ตรงลิงก์ `/exec` / Apps Script ยังไม่ได้ทำเวอร์ชันใหม่หลังวาง Code.gs เวอร์ชัน 2 / การตั้งค่า Deploy ต้องเป็น "ทุกคน" |
| "ไม่รู้จักคำสั่ง …" | Code.gs ใน Apps Script ยังเป็นเวอร์ชันเก่า — วางใหม่แล้วทำเวอร์ชันใหม่ |
| "ไม่พบแท็บ … รัน setupSystem ก่อน" | ยังไม่ได้รัน `setupSystem` หรือมีคนเปลี่ยนชื่อแท็บ |
| "ยังไม่ได้ตั้ง PIN_…" | เพิ่มในคุณสมบัติของสคริปต์ |
| GitHub ขึ้น 404 | รอ 2–3 นาทีหลังเปิด Pages / ตรวจว่ามี `index.html` อยู่ชั้นนอกสุดของ repository (ไม่ได้อยู่ในโฟลเดอร์ย่อย) |
| แก้ไฟล์บน GitHub แล้วหน้าเว็บไม่เปลี่ยน | รอ 1–2 นาที แล้ว Ctrl+Shift+R |
| หน้าตาไม่มีสี / ไม่มีปุ่มทำงาน | อัปโหลด style.css, common.js, config.js ไม่ครบ |
| Telegram ไม่ส่ง | รัน `testTelegram` ดู Execution log / บอทยังอยู่ในกลุ่มไหม |
| ลิงก์ใน Telegram ไม่มี | ยังไม่ได้กรอก `SITE_URL` ใน Code.gs (ขั้น C2) |

เจอข้อความอื่น: ถ่ายภาพหรือคัดลอกข้อความส่งมาให้ผู้ช่วย (อย่าส่ง PIN หรือ token)
